# Захиалгыг Google Sheets-д хүлээн авах

Сайтын захиалгын хуудас (`order.html`) захиалга бүрийг таны Google Sheet-д нэг мөр болгон нэмнэ.
Нэг удаа ~5 минут тохируулна.

## 1. Sheet үүсгэх
1. https://sheets.new нээж шинэ хүснэгт үүсгэнэ. Нэрийг жишээ нь `Ember&Bean захиалга` гэж өгнө.

## 2. Скрипт оруулах
1. Хүснэгтийн цэснээс **Extensions → Apps Script** дарна.
2. Нээгдсэн `Code.gs` доторх бүх кодыг устгаад, энэ хавтас дахь [`Code.gs`](Code.gs)-ийн агуулгыг бүтнээр нь хуулж тавина.
3. (Заавал биш) Шинэ захиалга бүрт и-мэйл авах бол `NOTIFY_EMAIL = ''` мөрөнд өөрийн и-мэйлийг бичнэ.
4. 💾 **Save** дарна.

## 3. Web app болгон нийтлэх
1. Баруун дээд буланд **Deploy → New deployment** дарна.
2. ⚙️ дүрсээс **Web app** сонгоно.
3. **Execute as:** `Me`, **Who has access:** `Anyone` гэж тохируулна.
4. **Deploy** дарна. Google зөвшөөрөл асуухад өөрийн бүртгэлээр **Allow** дарна
   ("Google hasn't verified this app" гарвал **Advanced → Go to … (unsafe)** — энэ бол таны өөрийн скрипт).
5. Гарч ирсэн **Web app URL**-ийг (`https://script.google.com/macros/s/…/exec`) хуулна.

## 4. Сайтад холбох
Энэ URL-ийг Claude-д өгөхөд `shop.js` доторх `ORDER_ENDPOINT`-д тавьж нийтэлнэ.
Хүсвэл дансны мэдээлэл (`BANK`) болон холбоо барих утсыг (`PHONE`) мөн тэнд оруулна.

## Анхаарах
- Үнэ өөрчлөгдвөл `shop.js` болон `Code.gs` доторх `PRICES`-ийг хоёуланг нь шинэчилнэ. Sheet-д бичигдэх нийт дүнг скрипт өөрөө тооцдог.
- `Code.gs`-ийг өөрчилсний дараа **Deploy → Manage deployments → ✏️ → Version: New version → Deploy** хийнэ. Ингэхэд URL өөрчлөгдөхгүй.
- "Төлөв" баганыг (Шинэ / Баталгаажсан / Хүргэгдсэн) гараар шинэчилж явна.
